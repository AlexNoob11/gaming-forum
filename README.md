Gaming Forum Client Project
A modern, responsive online gaming forum built for a client using PHP and MySQL, styled with Tailwind CSS, and enhanced with Vanilla JavaScript.

Tech Stack
Frontend: HTML5, Tailwind CSS, Vanilla JavaScript

Backend: PHP

Database: MySQL

 Features
User Authentication: Secure registration, login, and session management.

Discussion Boards: Create, read, update, and delete (CRUD) forum topics and replies.

Interactive UI: Fully responsive design optimized for mobile, tablet, and desktop devices using Tailwind CSS.

Dynamic Content: Real-time updates and interactive elements powered by Vanilla JavaScript.

Database Integration: Robust data storage and retrieval for users, posts, categories, and comments via MySQL.
